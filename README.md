# Stef Burgoci — Aplicații Android

## Convertor Unități și Valută

O aplicație pentru conversii și calcule de zi cu zi.

### Funcționalități

- Conversii de unități de măsură.
- Conversii valutare, cu afișarea datei cursurilor disponibile.
- Calculatoare pentru reduceri și preț pe unitate.
- Calculator pentru călătorii și împărțirea notei de plată.
- Favorite și istoric.
- Remindere valutare opționale.

Cursurile valutare sunt orientative. Sumele aplicate de bănci
sau case de schimb pot fi diferite.
